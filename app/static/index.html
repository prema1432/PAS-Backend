Your customers, their plans, in one place

PAS is a production-grade FastAPI backend with a Supabase backbone. Manage customers, provider API keys and plan minutes in one dashboard. Create an account with email and password — your password is never stored here: it is hashed by Supabase Auth, and your session travels in HttpOnly cookies: a short-lived JWT access token plus a rotating refresh token.

🔐

Encrypted auth

Passwords hashed with bcrypt by Supabase Auth. Sessions keep a short-lived JWT access token and a rotating refresh token in HttpOnly cookies no script can read.

🧩

Per-user data

Every customer record is scoped to its owner with Row Level Security enforced at the database layer.

⚡

FastAPI core

Typed, documented REST API with OpenAPI docs built in and async-ready services.

☁️

Cloud ready

Deployed on FastAPI Cloud with Supabase Postgres, storage, and auth in one stack.
